# Metronomly

A Chrome extension that auto-fetches BPM for any song. Build setlists and practice smarter.

BPM data provided by [GetSongBPM](https://getsongbpm.com).

## Features

- Search any song and instantly get its BPM
- Tap tempo
- 4/4, 3/4, 6/8, 5/4 time signatures
- Build and save a setlist

## Install

Load unpacked from Chrome Extensions (`chrome://extensions` → Developer mode → Load unpacked).
